# Privacy policy

The hgraph Development plugin is a skills-only package. It contains no
connector, MCP server, or automatically executed lifecycle hook, and it does
not collect, retain, or transmit personal data by itself.

The bundled skills provide instructions to the host agent for working with
source code in the user's selected workspace. Any model processing, local
command execution, network access, or third-party service use remains subject
to the host product's privacy policy, sandbox, approval settings, and any tools
the user has separately configured.

Privacy questions can be raised through the
[hgraph issue tracker](https://github.com/hhenson/hgraph/issues).
